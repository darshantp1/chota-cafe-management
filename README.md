# ☕ Chota Cafe Management System

## 📌 Project Overview

**Chota Cafe Management System** is a simple beginner-friendly Python project designed to manage customer orders in a small café.

The program displays a café menu, allows customers to enter item names and quantities, checks item availability, calculates the amount, and generates the final bill.

## 🛠️ Technologies Used

* Python
* VS Code

## ✨ Features

* Displays a café menu with 10 items
* Allows customers to enter item names instead of numbers
* Takes the quantity of each item
* Calculates the price automatically
* Checks whether an item is currently available
* Handles unavailable items
* Calculates the total bill
* Displays a final bill
* Simple and easy-to-understand Python code

## ⚙️ How It Works

1. The program displays the café menu.
2. The customer enters the item name.
3. The program checks whether the item is available.
4. The customer enters the quantity.
5. The program calculates the amount.
6. The customer can continue adding items.
7. The customer enters `done` when the order is complete.
8. The program displays the total bill.

## ▶️ How to Run

### 1. Open the project in VS Code

Open the `chota cafe management` folder in VS Code.

### 2. Run the Python file

Open the terminal and run:

```bash
python cafe.py
```

If `python` does not work, try:

```bash
py cafe.py
```

### 3. Enter the order

Example:

```text
Enter item name or type 'done' to finish: burger
Enter quantity: 2

Burger added. Amount = Rs. 200

Enter item name or type 'done' to finish: juice
Enter quantity: 1

Juice added. Amount = Rs. 50

Enter item name or type 'done' to finish: done

===== FINAL BILL =====
Total Bill = Rs. 250
Thank you! Visit again!
```
